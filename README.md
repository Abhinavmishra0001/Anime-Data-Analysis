# 📊 Data Analysis Practice with Pandas & NumPy

## 📌 Overview
This repository contains exploratory data analysis (EDA) projects and hands-on practice notebooks created to strengthen core Data Analysis skills using Python, Pandas, and NumPy. It features real-world and structured datasets to practice data cleaning, string manipulation, filtering, and metric calculation.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy
- **Environment:** Jupyter Notebook
